# 1. 專題定義

## 1.1 問題

香港的垃圾問題不只是堆填區空間不足，還有**污染**：可回收物放錯桶，或被食物弄髒的物料放入回收桶，會降低整批回收物的價值，甚至令整車送去堆填。一個設計良好的垃圾桶不能解決整個系統，但可以消除一個常見障礙——使用者要在丟棄的那一刻快速、有信心地做決定。

現時大部分公眾垃圾桶都是被動的，只靠標籤、顏色和使用者的知識。回收行為研究普遍指出，物料混淆、標籤不清和不方便，是污染的主要原因。一個能**看見物件、量重量、檢查濕度和金屬、決定分類、記錄事件**的垃圾桶，可以令分類更可靠，並為大廈或校園提供有用數據。香港減廢與回收背景可參考 [1]。

這個題目適合作為畢業專題，因為它結合：

- 機械設計（抽屜、料斗、活門、旋轉滑槽、受力路徑）；
- 嵌入式系統（ESP32、感測器、步進／伺服、安全連鎖）；
- 電腦視覺（資料集、遷移學習、TFLite）；
- App／雲端／數據（本地網頁 App、資料庫、可選雲端同步）；
- 工程評估（準確率、週期時間、卡料率、成本、可用性）。

本方案的設計刻意做到**低成本、可維修**：夾板、標準塑膠桶、3D 打印支架、Raspberry Pi Zero 2 W、ESP32 和現成感測器。它不用工業 PLC、六軸機械臂或訂製注塑外殼。

## 1.2 專題目標與具體目標

**總目標：** 設計、製作並評估一個低成本智能垃圾桶，每次處理一件垃圾，分為四類——膠樽、金屬、濕垃圾、乾／其他——使用鏡頭和小型感測器組，並用手機 App 記錄每次事件。

| 編號 | 具體目標 | 如何量度 |
|---|---|---|
| O1 | 四類整體準確率至少 85% | 50 件混合測試，三次，混淆矩陣 |
| O2 | 一次分類週期 ≤10 秒（不計使用者放置時間） | 50 次計時／日誌時間戳 |
| O3 | 至少 90% 成功分類，無卡料或需手動重設 | 50 次可靠性測試 |
| O4 | 滿度估算誤差 ≤±10% | 與尺量高度比較（25%、50%、75%、100%） |
| O5 | 製作成本 ≤ HK$4,500 | 最終 BOM 與收據 |
| O6 | 蓋、抽屜或料斗門打開時不得動作；急停 100 ms 內停止 | 每個連鎖 10 次測試 |
| O7 | 記錄時間、類別、信心度、重量、濕度、金屬、桶號、滿度；可匯出 CSV | 檢查 App／資料庫 |
| O8 | 產生可重複的製作與測試記錄，供最終報告使用 | 工作日誌、照片、測試表、程式碼倉庫 |

**1.0 版不包含：** 紙張／玻璃獨立分類、壓縮、除臭、戶外防水、一次處理多件、尖銳／醫療垃圾、認證安全等級。這些是未來工作，不是失敗。

### 限制與假設

- 在學校工房或家中用手工具製作；公差 ±2 mm，不是機械加工精度。
- 鏡頭從固定蓋向下看；環境光由環形燈控制。
- 使用者分類前會關蓋；蓋打開時機器拒絕動作。
- 原型在室內平整地面示範。
- App 在手機／電腦上，與 Pi 同一 Wi-Fi；雲端可選。
- 使用公制螺絲和 mm 尺寸。

## 1.5 成功準則

成功的原型不是「模型在我的資料集上達到 99%」，而是：

1. 對 50 件真實混合垃圾，整體準確率 ≥85%，而且沒有不安全行為；
2. ≥90% 週期無卡料；
3. 每次事件都記錄正確；
4. 一個學生用指定工具就能製作和維修；
5. 不超預算；
6. 有證據——照片、日誌、混淆矩陣、時間、失敗記錄——讓你在報告和答辯中站得住腳。

## 1.6 標準、安全與學術背景

這是原型，不是認證產品。但仍應按良好做法設計：

- **電氣：** 12 V SELV；電池正極加保險絲；獨立降壓模組；應力消除；無裸露導體；急停切斷執行器電源。
- **電池：** 有 BMS 的認證 3S 電池組；在外殼外充電；防火袋；不無人看管充電。
- **機械：** 蓋鉸鏈、抽屜、活門、滑槽加護罩；極限開關；護罩打開不動作；圓角或包邊。
- **衛生：** 可拆除 PP 內襯；矽膠密封；滴水盤；測試濕垃圾後清潔；戴手套。
- **數據：** 本地優先；不收集個人資料；影像可刪除；App 在私人網絡。
- **學術：** 引用來源；寫工作日誌；記錄失敗；不要聲稱未測試的功能。
